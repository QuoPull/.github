# Code of conduct

QuoPull's repositories are for building and reviewing the protocol. Everyone taking part, in issues, pull
requests, discussions and reviews, is expected to:

- be respectful, and criticise code and ideas rather than people;
- keep discussion on topic and in good faith;
- never harass, threaten, or post anyone's private information;
- never use these spaces to promote tokens, sales or other projects.

Maintainers may edit or remove comments, close threads, and block accounts that break these rules. To report
a problem with someone's conduct, contact the maintainers through the QuoPull organization page on GitHub,
or for anything sensitive, through a private security advisory on the repository concerned.
