# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub's private vulnerability reporting: open the repository, go to the
**Security** tab and choose **Report a vulnerability**. For the QuoPull contracts that is
<https://github.com/QuoPull/qpull/security/advisories/new>.

Include what you found, the contract and function involved, and the steps or a test that shows it. We will
reply in the same advisory thread.

## Scope

The contracts in [QuoPull/qpull](https://github.com/QuoPull/qpull) that are deployed on Robinhood Chain
(chain id 4663). Their addresses are listed in
[docs/DEPLOYMENTS.md](https://github.com/QuoPull/qpull/blob/main/docs/DEPLOYMENTS.md). The website and the
off-chain keeper and draw bot in the same repository are in scope too.

Archived repositories are out of scope.
